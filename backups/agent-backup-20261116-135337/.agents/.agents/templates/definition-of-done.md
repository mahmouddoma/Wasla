# Definition of Done — Wasla feature

Complete only those relevant to the ticket; mark Not Applicable with reason.

- [ ] Correct actor, requirement and all AC mapped to behavior
- [ ] Real API contract or clearly labeled missing backend evidence
- [ ] Valid/invalid inputs, permission denied, concurrent updates, duplicate submit
- [ ] Loading / empty / error / success / offline states
- [ ] Desktop + tablet + mobile task completion
- [ ] Arabic + English, RTL + LTR, long content and focus behavior
- [ ] Accessibility and touch targets checked for critical flows
- [ ] No PHI/secrets exposed; server enforcement not replaced by UI guard
- [ ] Focused tests pass; broader regressions when risk demands
- [ ] Backend/Jira status and release dependencies honestly stated

**No evidence = not verified.** A build alone cannot validate user experience or server API.
