# Wasla visual invariants
- Inspect existing tokens, approved logo and the UI being improved; preserve the actual brand, never copy unrelated brand palette.
- Clean, premium healthcare SaaS with calm hierarchy; avoid unnecessary gradient backgrounds, stacked cards, boxed crumbs and heavy shadows.
- Design for goal completion by each role. Do not impose a uniform layout across very different workflows.
- Arabic/English translations must preserve meaning, formatting, number/date context and logical direction; test mirrored icons, overlays and focus order.
- Treat mobile as a UX design deliverable with its own density, navigation, hierarchy, forms and actions, not only CSS breakpoints.
- Handle empty/error/loading/offline and long-label cases; follow keyboard/touch access, visible focus and reduced motion.
- Refer to `wasla-ui-ux`, `wasla-mobile-experience`, `knowledge/brand-and-ux.md` only when relevant.
