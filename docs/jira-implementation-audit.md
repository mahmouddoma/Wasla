## Integration blocker

The supplied API base is `http://192.168.1.6:8085`. Current Swagger has 94 paths and no reservation, suspension-impact or assignable-permissions paths. Five anonymous read-only probes return 404; [probe results](browser-verification/reservations/backend-probe.json). These responses establish endpoint unavailability on the supplied deployment, not authenticated business-rule acceptance. Rich reservation and suspension projections require confirmation against the deployed Phase 10 schema. Capacity changes, authority revocation, cutoff enforcement and system cancellation remain server responsibilities.
