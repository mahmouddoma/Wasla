# وصلة — العرض التعريفي لبوابة الدكتور

عرض بيع عربي مختصر، 9 شرائح، مدة تقديم مقترحة نحو 5 دقائق.

## الملفات

- `Wasla-Doctor-Portal.pptx`: نسخة PowerPoint قابلة لتعديل النصوص والأشكال، مع ملاحظات للمقدّم.
- `Wasla-Doctor-Portal.pdf`: نسخة ثابتة جاهزة للمشاركة، 9 صفحات أفقية.
- `Wasla-Doctor-Portal.html`: نسخة مستقلة للمتصفح؛ افتحها ثم اختر «وضع العرض». استخدم السابق والتالي أو أسهم لوحة المفاتيح؛ Escape للخروج من وضع العرض.
- `presenter-guide.md`: شرح مختصر لكل شريحة وأسئلة تساعد في تقديم العرض ومراجع الميزات داخل المشروع.
- `preview/`: صور معاينة للشرائح.

## حدود المحتوى

المحتوى مبني على مكونات ومسارات المشروع الحالية، وليس إثباتًا لتشغيل جميع الخدمات على بيئة إنتاج. تتضمن الشرائح 3–8 لقطات فعلية من الحساب التجريبي: الرئيسية، والحجوزات، وسجل المرضى، والعيادات، والإيرادات، والتقارير. بيانات تعريف المرضى وبيانات الاتصال محجوبة. الأرقام الظاهرة في اللقطات تخص بيانات الحساب التجريبي، ولا تمثل نتائج تجارية أو وعودًا لعيادة العميل. تفاصيل الإتاحة تعتمد على الصلاحيات والخدمات المتصلة. الصور النهائية المضمّنة في العرض موجودة في `screenshots/`، ولا يتضمن المولّد بيانات تسجيل الدخول.

العرض موجّه للدكتور؛ الملاحظات التفصيلية والمراجع موجودة في دليل المقدّم وملاحظات PowerPoint فقط. عند مشاركة العرض مع الطبيب، يكفي إرسال PDF.

## إعادة التوليد

من جذر المشروع:

```powershell
npm install --prefix .tmp/presentation-tools --no-package-lock --ignore-scripts pptxgenjs playwright
node docs/presentations/doctor-portal/build.cjs
```

يستخدم التوليد Chrome المثبّت في المسار المحدد داخل `build.cjs` لتصدير PDF والمعاينات. خط Tahoma مستخدم لتوافق العربية على Windows؛ PDF يحتفظ بمظهر النصوص. تبقى اعتماديات التوليد داخل `.tmp` ولا تعدّل اعتماديات تطبيق Angular.
